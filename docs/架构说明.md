# 架构说明

## 总体结构

```
┌─────────────────────────── UI 线程（WinForms）───────────────────────────┐
│  Program.cs      单实例互斥 → MappingConfig.Load() → 启动托盘            │
│  TrayContext.cs  NotifyIcon + 菜单；订阅 Mapper 事件刷新托盘文字/勾选     │
│  SettingsForm.cs 设置界面；编辑配置副本 → Mapper.ApplyConfig() 热更新     │
└──────────────────────────────────┬───────────────────────────────────────┘
                                   │ ApplyConfig / SetEnabled / 事件回调
┌──────────────────────────────────▼───────────────────────────────────────┐
│  Mapper.cs       后台轮询线程（AboveNormal，默认 8ms）                    │
│    1. XInput.GetState(0) 读手柄                                        │
│    2. 组合键检测（ToggleChord，边沿触发）→ Toggle()                     │
│    3. 移动摇杆 → 死区/曲线整形 → SetCursorPos（亚像素累计）              │
│    4. 滚动摇杆 → 整格累计 → SendInput(WHEEL/HWHEEL)                     │
│    5. 按键映射 → 上一帧集合对比边沿 → SendInput(按下/弹起/滚轮)          │
└──────────┬─────────────────────────────┬─────────────────────────────────┘
           │                             │
   XInput.cs（原生）              MouseSimulator.cs（原生）
   动态加载 xinput1_4/1_3/9_1_0   SendInput / SetCursorPos
```

## 关键设计

### 1. 组合键开关（手柄唯一控制入口）

- `ToggleChord` 是按键名列表，要求**同时按住**；用 `_chordLatch` 做防抖（按住期间只触发一次，全部松开才允许下一次触发）。
- 组合键检测在映射关闭时同样执行（`ProcessFrame` 中先于"已禁用"分支），保证**关了也能用手柄打开**。
- 切换时可选震动反馈（`XInputSetState` 短促震动 220ms）。

### 2. 摇杆 → 光标移动

```
n = 轴值归一化 [-1,1] → 若 |n| ≤ 死区输出 0
t = (|n| - 死区) / (1 - 死区)
输出 = sign(n) · t^Curve        // Curve>1 时轻推精细、推满快速
dx = 输出 · Sensitivity · dt    // 速度单位 像素/秒，按帧时长 dt 积分
```

- 用 **`SetCursorPos`（物理坐标）** 而非 `SendInput` 相对移动：绕开 Windows 指针加速度，位移可控可预测；同时兼容 DPI 缩放（物理像素）。
- 帧间不满 1px 的余量存入 `_moveAccX/Y` 亚像素累计器，慢速移动不丢步。
- 手柄 Y 轴向上为正、屏幕 Y 轴向下为正，取反后使用。

### 3. 按键边沿与"防卡键"

- 每帧生成"当前按下集合"（扳机按 `TriggerThreshold` 阈值判定并入集合），与 `_prevHeld` 集合对比得到按下/弹起边沿，保证长按 = 持续按住鼠标键（可拖拽）。
- 点击类动作（左/右/中键）按下时记入 `_heldMouseActions`；**映射关闭、手柄断开、程序退出**三个路径都会 `ReleaseAllHeld()` 强制弹起，避免"卡键"。

### 4. XInput 动态加载

`XInput.cs` 用 `NativeLibrary.TryLoad` 依次尝试 `xinput1_4.dll`、`xinput1_3.dll`、`xinput9_1_0.dll`，`GetProcAddress` 取 `XInputGetState/XInputSetState` 转委托调用——一个实现兼容三种常见的 XInput 发行版本，无需额外依赖（如 xi liner 的 SDL）。

### 5. 配置与线程模型

- 配置为纯 POCO（`MappingConfig`），`System.Text.Json` 序列化到 `%APPDATA%\GamepadMouse\config.json`；加载失败自动备份 `.bad` 并回退默认。
- 界面编辑的是配置**副本**，点保存才 `ApplyConfig` + 落盘；轮询线程每帧通过 `_configLock` 取快照，配置热更新无需重启线程。
- Mapper → UI 的回调（开关状态、手柄连接状态）经 `Control.BeginInvoke` 封送回 UI 线程。

## 已知边界

- 仅支持第一个连接的手柄（`dwUserIndex=0`），4 个手柄扩展只需把 userIndex 提为配置项。
- 仅支持 XInput 手柄；DirectInput/HID 手柄需要换成 Raw Input / HID 解析（接口上只需替换 `XInput.GetState` 一个数据源）。
- `SetCursorPos` 在多显示器下同样适用（坐标为虚拟屏幕物理坐标）。
