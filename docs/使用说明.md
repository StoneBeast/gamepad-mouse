# 使用说明

## 1. 启动

运行 `GamepadMouse.exe` 后程序进入系统托盘（没有主窗口），托盘图标旁悬停可看到当前状态：

- 「映射已开启」— 手柄正在控制鼠标
- 「映射已关闭」— 手柄不生效，但**组合键开关依然有效**
- 「手柄未连接（等待中…）」— 插上手柄即自动恢复

托盘图标也会随状态变色：映射开启时手柄图案 + 绿色状态点，关闭时变灰。

双击托盘图标打开设置（或用命令行 `GamepadMouse.exe --settings` 直接打开），右键托盘图标打开菜单：

| 菜单项 | 说明 |
|---|---|
| 启用鼠标映射 | 手动开关（平时用组合键即可） |
| 设置… | 打开设置窗口 |
| 开机自动启动 | 写入/删除 HKCU 注册表自启项 |
| 退出 | 释放资源并退出 |

## 2. 用手柄开关映射

默认组合键：**同时按住 `Back + Start`**，每按一次切换一次开/关，切换时手柄短暂震动一下作为反馈：

- 震动 = 映射状态切换成功（具体开关状态以托盘文字为准）。
- 组合键在映射关闭时同样有效，因此**关闭后仍可以用手柄重新打开**，全程不需要鼠标键盘。

### 录制自定义组合键

1. 双击托盘图标 →「开关映射的组合键」区域 → 点「录制组合键…」；
2. 在手柄上**同时按住**想用的按键，弹窗会实时显示当前按住的键；
3. 点「使用当前按键」完成录制；
4. 点「保存并应用」。

也可以把任意单个按键的功能设为「★ 开关映射」，实现单键开关。

> 提示：组合键的按键最好不要再映射其他鼠标动作（默认的 Back/Start 未映射任何动作），否则单独按它们时仍会触发各自的动作。

## 3. 自定义按键映射

设置窗口的「按键映射」表格中，每一行是一个手柄按键，下拉选择它对应的鼠标动作：

| 动作 | 行为 |
|---|---|
| 鼠标左键 / 右键 / 中键 | 按住 = 按下，松开 = 弹起（可拖拽、长按） |
| 左键双击 | 按下时发送双击 |
| 滚轮上/下/左/右 | 按下时滚动一格 |
| ★ 开关映射 | 按下时切换映射开/关 |
| （无） | 不映射 |

## 4. 摇杆与手感调校

设置窗口采用深色现代风格，顶部为**映射总开关**（拨动开关 + 状态胶囊，与托盘/组合键实时联动）和**主题切换器（深色/浅色）**，下方为各设置卡片。

- **主题**：点击头部「深色 / 浅色」分段开关即时切换整套配色（含窗口标题栏），选择会自动记忆，下次启动保持。

- **移动摇杆**：左/右摇杆二选一（默认右摇杆），分段选择器切换。
- **滚动摇杆**：另一个摇杆控制滚轮，上下滚动、左右水平滚动；也可以设为「不使用」。
- **光标速度**：满偏移时的速度（像素/秒），默认 2500，拖动滑杆调节。
- **死区**：摇杆中心的小范围不响应区，默认 0.18；光标自己漂移时调大，轻微推动没反应时调小。
- **响应曲线**：默认 1.60。值越大，轻推越慢、推满越快，越适合精细操作；1.00 为线性。
- **轮询间隔**：默认 8ms（约 125Hz），一般无需修改。

修改后点「保存并应用」立即生效，无需重启程序；「恢复默认」可一键还原。

## 5. 配置文件位置

```
%APPDATA%\GamepadMouse\config.json   配置
%APPDATA%\GamepadMouse\log.txt       日志（超过 1MB 自动轮转）
```

高级用户可直接编辑 JSON（字段含义见 README），保存后重启程序生效；格式写坏时程序会自动备份为 `config.json.bad` 并回退默认配置。

## 6. 注意事项

- 仅支持 **XInput** 手柄（Xbox 及以 360/XInput 模式连接的手柄；DirectInput 模式请切换手柄背后的模式开关）。
- 需要控制管理员权限的窗口（如任务管理器）时，请以管理员身份运行本程序（Windows UIPI 限制，任何模拟输入软件都受此限制）。
- 程序为单实例运行，重复启动只会弹提示。
- 退出程序前若正按着手柄按键，程序会自动弹起所有按住的鼠标键，不会卡键。
