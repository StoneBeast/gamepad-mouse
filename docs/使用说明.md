# 使用说明

## 1. 启动

运行 `GamepadMouse.exe` 后程序进入系统托盘（没有主窗口），托盘图标旁悬停可看到当前状态：

- 「映射已开启」— 手柄正在控制鼠标
- 「映射已关闭」— 手柄不生效，但**组合键开关依然有效**
- 「手柄未连接（等待中…）」— 插上手柄即自动恢复

托盘图标也会随状态切换：映射开启时为彩色手柄图标，关闭时变灰阶。

双击托盘图标打开设置（或用命令行 `GamepadMouse.exe --settings` 直接打开）；设置窗口打开后，点击任务栏上的程序图标可在「显示并置顶」与「最小化」之间切换。右键托盘图标打开菜单：

| 菜单项 | 说明 |
|---|---|
| 启用鼠标映射 | 手动开关（平时用组合键即可） |
| 设置… | 打开设置窗口 |
| 开机自动启动 | 注册/删除计划任务（登录时以最高权限启动，不弹 UAC 确认框） |
| 关于… | 打开「关于」窗口（版本信息 / 检查更新） |
| 退出 | 释放资源并退出 |

设置窗口「行为」卡片中的三个开关（开机自启 / 启动时开启映射 / 开关时震动反馈）**切换后立即生效**，无需点「保存并应用」；开关也支持按住拖动滑块切换。

## 2. 用手柄开关映射

默认组合键：**同时按住 `Back + Start`**，每按一次切换一次开/关，切换时手柄震动作为反馈：

- 短震 = 映射已开启；长震 = 映射已关闭（具体开关状态以托盘文字为准）。
- 组合键在映射关闭时同样有效，因此**关闭后仍可以用手柄重新打开**，全程不需要鼠标键盘。

### 录制自定义组合键

1. 双击托盘图标 →「开关映射的组合键」区域 → 点「录制组合键…」；
2. 在手柄上**同时按住**想用的按键，弹窗会实时显示当前按住的键；
3. 点「使用当前按键」完成录制；
4. 点「保存并应用」。

也可以把任意单个按键的功能设为「★ 开关映射」，实现单键开关。

> 提示：组合键的按键最好不要再映射其他鼠标动作（默认的 Back/Start 未映射任何动作），否则单独按它们时仍会触发各自的动作。

## 3. 自定义按键映射

设置窗口的「按键映射」表格中，每一行是一个手柄按键，下拉选择它对应的鼠标动作：

| 动作 | 行为 |
|---|---|
| 鼠标左键 / 右键 / 中键 | 按住 = 按下，松开 = 弹起（可拖拽、长按） |
| 左键双击 | 按下时发送双击 |
| 滚轮上/下/左/右 | 按下时滚动一格 |
| ★ 开关映射 | 按下时切换映射开/关 |
| （无） | 不映射 |

## 4. 摇杆与手感调校

设置窗口采用深色现代风格，顶部为**映射总开关**（拨动开关 + 状态胶囊，与托盘/组合键实时联动）和**主题切换器（深色/浅色）**，下方为各设置卡片。

- **主题**：点击头部「深色 / 浅色」分段开关即时切换整套配色（含窗口标题栏），选择会自动记忆，下次启动保持。

- **移动摇杆**：左/右摇杆二选一（默认右摇杆），分段选择器切换。
- **滚动摇杆**：另一个摇杆控制滚轮，上下滚动、左右水平滚动；也可以设为「不使用」。
- **滚轮模式**：
  - **平滑滚动**（默认）：滚轮增量随摇杆力度连续变化，与光标手感一致——**轻推慢滚、重推快滚**，轻推是细腻的连续慢滚，不是偶尔跳一格；
  - **整格滚动**：攒满一格（120）才发送，兼容只认整格滚轮增量的旧程序。
- **光标速度**：满偏移时的速度（像素/秒），默认 2500，拖动滑杆调节。
- **死区**：摇杆中心的小范围不响应区，默认 0.18；光标自己漂移时调大，轻微推动没反应时调小。
- **响应曲线**：默认 1.60。值越大，轻推越慢、推满越快，越适合精细操作；1.00 为线性。
- **轮询间隔**：默认 8ms（约 125Hz），一般无需修改。

修改后点「保存并应用」立即生效，无需重启程序；「恢复默认」可一键还原。

## 5. 关于窗口与检查更新

设置窗口左下角「关于」按钮或托盘菜单「关于…」可打开**关于**窗口，显示当前版本、项目主页（GitHub）与开源许可。

- **检查更新**：点击「检查更新」会查询 GitHub Releases 的最新发布版本（数据来自 `api.github.com`，需联网）：
  - 已是最新 → 提示「当前已是最新版本」；
  - 有新版本 → 显示新版本号并出现「前往下载」按钮，点击打开对应 Release 页面（程序本身不自动下载/安装，由你决定是否升级）；
  - 网络失败 → 提示检查失败，详情写入日志。
- 当前版本显示在窗口头部（「版本 x.y.z」），与程序集版本一致。

## 6. 配置文件位置

配置为**便携式设计**：`config.json` 与 `log.txt` 都保存在程序所在目录，随目录一起迁移；若目录不可写（如受保护的安装位置），自动回退到 `%APPDATA%\GamepadMouse`。从旧版本升级时，`%APPDATA%` 里的原有配置会自动迁移到程序目录。

高级用户可直接编辑 JSON（字段含义见 README），保存后重启程序生效；格式写坏时程序会自动备份为 `config.json.bad` 并回退默认配置。

## 7. 注意事项

- 仅支持 **XInput** 手柄（Xbox 及以 360/XInput 模式连接的手柄；DirectInput 模式请切换手柄背后的模式开关）。
- 程序通过内嵌 manifest **始终以管理员身份运行**（启动时可能弹出一次 UAC 确认框），因此可以操作管理员权限的窗口（如鸣潮等游戏启动器、任务管理器）。若通过兼容性设置等方式改为普通权限运行，程序会弹出托盘气泡提醒，此时代码受 Windows UIPI 限制无法操作管理员权限的窗口。
- 程序为单实例运行，重复启动只会弹提示。
- 退出程序前若正按着手柄按键，程序会自动弹起所有按住的鼠标键，不会卡键。
